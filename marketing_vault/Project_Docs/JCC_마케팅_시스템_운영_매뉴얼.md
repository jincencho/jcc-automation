# 🏆 JCC 진센조 마케팅 자동화 시스템 운영 매뉴얼 (v4.0)

이 문서는 Antigravity AI와 함께 구축한 JCC 마케팅 시스템의 핵심 로직과 매일의 업무 절차를 정리한 공식 지침서입니다.

---

## 💎 1. 핵심 마케팅 로직 (Core Logic)

### 👨‍🏫 1.1 전문가 스토리텔링 (19년 마스터)
- **로직**: 단순 판매자가 아닌 **'서비스(수리) - 물류(설치) - 영업(설계)'**를 모두 거친 유일무이한 19년 마스터임을 강조.
- **메시지**: "가전의 속을 아는 사람이 설계도 가장 잘 합니다."

### 🔄 1.2 삼성 AI 가전 구독 클럽 전략
- **타겟**: 전국 어디서나 초기 비용 없이 프리미엄 가전을 쓰고 싶은 고객.
- **핵심 전략**: 전국 비대면 상담, 블루패스/AI케어 혜택 강조, 0원 라이프.

### 🏢 1.3 신규입주 단지 특화 전략 (최종 확정 및 시스템 통합)
- **타겟**: 영남권(부산·울산·경남·경북·대구) 입주 6개월 전 고객.
- **핵심 로직 (Standard)**:
    - **스토리텔링**: 19년 마스터 설계 + 진주 힐링 투어(맛집 '하연옥' 등) + 5대 입주 체크리스트 제공.
    - **해시태그**: 지역 카페 우선순위 배치 + 네이버 SEO 100자 최적화 (Max 30개).
    - **비주얼**: 가전/로컬/미식 3종 이미지 세트 (딥네이비&골드, 글래스모피즘, 실사 푸드 샷).
    - **연동**: 워드 파일 내 하이퍼링크 자동 변환을 통한 블로그 상담 유도 최적화.
- **주력 채널**: 네이버 블로그(신뢰도 기반), 인스타그램(비주얼 훅).

### 🌍 1.4 전국구 비대면 서비스
- **전략**: 모든 타겟에 대해 전국 어디서나 비대면 원스톱 서비스가 가능함을 강조.
- **키워드**: "매장 방문 불필요", "카톡 5분 견적", "전국 무료 배송/설치".

### 🤵 1.5 혼수(Wedding) 특화 전략 (광역 하이브리드 솔루션)
- **타겟**: 부울경(부산·울산·경남) 전역의 예비부부 (2시간 내외 전 지역 포함).
- **핵심 로직**:
    - **컴플라이언스 준수**: 타사(LG, 엘지 등) 직접 언급 절대 금지. "타 브랜드 대비", "압도적 통합 혜택" 표현 사용.
    - **핵심 공식**: "AI 가전 = 삼성" 공식을 적극 활용하며 트렌디한 밈(럭키비키 등) 사용.
    - **거리 마케팅**: "고속도로 1시간 내외"임을 강조하여 심리적 장벽 해소.
    - **하이브리드 큐레이션**: 백화점 프리미엄 모델 + 로드샵 실속 모델의 전략적 혼합 설계.
- **상담 프로세스**: 매장 방문 전 **전용 홈페이지를 통한 비대면 상담** 우선 권장.

## 🏷️ 2. 콘텐츠 생성 가이드라인

### 🔗 2.1 공식 홈페이지 연동
- 모든 네이버 블로그 원고 하단에 전용 홈페이지 링크 자동 삽입.
- URL: `https://jcc-band.vercel.app/`

### 📱 2.2 SNS 채널별 최적화
- **네이버 블로그**: 전문 지식과 일기 형식을 결합한 장문 스토리텔링.
- **인스타그램**: 6장의 카드 뉴스(카루셀) 이미지와 핵심 훅 중심의 캡션.
- **유튜브 쇼츠**: 15초 내외의 강렬한 자막 중심 스크립트.
- **페이스북/스레드**: 정보 공유 및 프로필 링크 유도형 짧은 글.

### #️⃣ 2.3 네이버 블로그 해시태그 가이드라인 (3-3-4 로직)
- **제한**: 최대 30개 태그, 총합 **100글자 이내** (네이버 SEO 최적화).
- **혼수 타겟 구성**:
    - 인기검색어 3개 + 웨딩 커뮤니티 3개 + 삼성 AI 가전 4개 + 기본 태그.
- **핵심 키워드**:
    - **AI 가전**: 스스로 관리하고 제안하는 삼성만의 스마트 기술.
    - **럭키비키**: "가전 졸업 완전 럭키비키잖아🍀" 트렌드 반영.

## 📸 3. 비주얼 전략 (Visual Strategy)

- **디자인 컨셉**: **Deep Navy & Gold Premium**
    - 배경: 딥네이비 (`#0A0E1A`) - 신뢰와 전문성 강조.
    - 텍스트: 골드 그라데이션 - 프리미엄 브랜드 가치 전달.
    - 타겟별 고화질 배경 이미지 (Interior, Luxury Living, Smart Kitchen 등) 적용.
- **인스타 카루셀 (9 Slides - 혼수 특화)**:
    1. **Cover**: 후킹 밈 (예: "가전 졸업 럭키비키🍀")
    2. **USP**: "AI 가전 = 삼성" 기술력 강조.
    3. **Solution**: 백화점+로드샵 하이브리드 설계.
    4. **Ease**: 전용 홈페이지 비대면 상담 유도.
    5. **Distance**: 부울경 1시간 거리 강조 (비주얼Sign).
    6~8. **Local**: 진주 투어(맛집/카페/명소) 힐링 큐레이션.
    9. **CTA**: 프로필 링크 유도.
- **듀얼 이미지 (Blog)**: 가전 훅 이미지 + 진주 로컬 이미지의 전략적 배치.

## 📅 4. 매일의 업무 루틴 (Daily Workflow)

1.  **시스템 실행**: `node scripts/daily_viral_task.js` 실행 (오전 중).
2.  **결과물 확인**: 당일 날짜 폴더(예: `2026-05-12/`) 확인.
3.  **검수 및 업로드**:
    - `.md` 파일을 열어 원고 내용 확인.
    - `insta_carousel_...` 이미지 6장을 인스타그램에 순서대로 업로드.
    - 블로그 원고 복사 후 전용 홈페이지 링크 확인.
4.  **피드백**: 고객 문의 패턴이나 인기 있는 해시태그가 생기면 `marketing_strategy.json` 업데이트 요청.
