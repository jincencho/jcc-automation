# 👋 JCC 마케팅 보관소에 오신 것을 환영합니다!

이 보관소(Vault)는 진센조 프로젝트의 모든 마케팅 활동을 체계적으로 관리하기 위해 만들어졌습니다. 처음 사용하시는 분들을 위한 간단 가이드를 드립니다.

## 1️⃣ 보관소 열기 (가장 먼저 할 일)
1.  옵시디언 앱을 실행합니다.
2.  왼쪽 하단의 **'다른 보관소 열기'** (금고 모양 아이콘)를 클릭합니다.
3.  **'폴더를 보관소로 열기'** 버튼을 누릅니다.
4.  내 컴퓨터에서 `c:\jincenchoproject\marketing_vault` 폴더를 선택합니다.

## 2️⃣ 핵심 화면 보기
- **[[Dashboard|📊 대시보드]]**: 보관소를 열면 가장 먼저 이 파일을 클릭해 보세요. 오늘 할 일과 최신 원고 현황이 한눈에 보입니다.
- **왼쪽 파일 탐색기**: 
    - `Targets`: 아파트 단지별 정보가 들어있습니다.
    - `Calendar`: 날짜별로 생성된 마케팅 리포트가 들어있습니다.
    - `Manuscripts`: 작성된 모든 원고가 보관되는 곳입니다.

## 3️⃣ 편리한 기능 활용
- **그래프 뷰 (Graph View)**: 왼쪽 바의 그물망 모양 아이콘을 누르면 아파트 단지와 원고들이 어떻게 연결되어 있는지 시각적으로 볼 수 있습니다.
- **링크 클릭**: `[[문수로 푸르지오 어반피스]]` 처럼 대괄호로 감싸진 글자를 클릭하면 해당 정보로 바로 이동합니다.

## 4️⃣ 도움 받기
- `Project_Docs`: 이 시스템이 어떻게 돌아가는지 궁금할 때 읽어보세요.
- `System_Knowledge`: 옵시디언 내 AI 기능을 사용할 때 참고할 가이드입니다.
