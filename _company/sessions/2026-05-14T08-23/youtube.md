# 📺 레오 — 선택된 작업을 위한 영상 기획, 썸네일 생성

 1. 가치 있는 단일 작업 결정
   - 회사 목표, 개인 목표, 최근의사결정, 메모리를 검토하여 지금 가장 가치 있는 단일 작업을 결정합니다.
   - 예: "경쟁 채널에서 핵심 키워드로 만든 영상 제목, 썸네일 생성"

2. 에이전트 할당
   - 적절한 1~2명의 에이전트에게 선택된 작업을 분배합니다.
   - 예: "로봇 LLM(Ollama/LM Studio)에게 트렌드 스나이퍼를 실행하고, 결과를 통해 영상 제목, 썸네일을 생성합니다."

3. 에이전트 작업 시작
   - 에이전트가 선택된 작업을 실행합니다.

4. 결과 확인 및 평가
   - 도구를 사용하여 생성된 파일 또는 데이터를 확인합니다.
   - 예: "영상 제목, 썸네일 등"

5. 진행 중/완료 판단
   - 작업의 진행 상황을 평가하여 목표를 달성하고 있는지 판단합니다.
   - 예: "생성된 영상 제목, 썸네일은 의미 있고 괄리가 없으므로 진행 중입니다."

6. 다음 단계 정하기
   - 도구를 사용하여 생성된 파일 또는 데이터를 바탕으로 다음 단계를 정합니다.
   - 예: "완료된 영상을 YouTube에 업로드한 후, 메모리에서 추가적인 의미 있는 데이터를 얻어 추가 작업을 계획합니다."

7. CEO 지시 확인
   - CEO의 지시 또는 새로운 목표에 따라 프로세스를 반복합니다.
